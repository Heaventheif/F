# دمج Fahim API مع SunkenBot

لا توجد واجهة عامة لتشغيل أي endpoint. رُبطت الواجهات المناسبة داخل أوامر قائمة أو أوامر جديدة أحادية الوظيفة. لم تُفعّل الواجهات الـ316 كلها عشوائياً؛ استخدمت المسارات التي تطابق وظيفة البوت ويمكن تطبيع ردها والتحقق منها، واستُبعدت واجهات Anime وNSFW.

| الأمر | الدمج |
|---|---|
| `tr` / `ترجم` | يجرّب مزودي الترجمة الحاليين أولاً، ثم Fahim V7 وV6 وV4 وV3. رسائل الفشل عربية، والنص الناتج بلغة الهدف التي يطلبها المستخدم. |
| `gptx` | أضيف Gemini V3 من Fahim كآخر مزود احتياطي. تُطلب العربية افتراضياً مع احترام طلب صريح بلغة أخرى. |
| `quran` | عند تعطل المصدر الأساسي، يجلب السورة من Fahim ويعرض الآيات المطلوبة. يذكر الرد أن التفسير الميسر غير متوفر في المصدر الاحتياطي. |
| `autodl` | كان يستخدم Fahim All Site احتياطياً لتنزيل الوسائط، وواجهة Fahim القديمة احتياطياً لـInstagram؛ أُبقي التكامل الموجود وعُرّبت أسماء المنصات الظاهرة. |

## أوامر أحادية الوظيفة

| الأمر | الوظيفة |
|---|---|
| `fact` / `معلومة` | معلومة عامة عشوائية بالعربية. |
| `trivia` / `سؤال` | سؤال معلومات عامة مع الخيارات والإجابة الصحيحة بالعربية. |
| `quote` / `نصيحة` | نصيحة قصيرة بالعربية. |
| `joke` / `نكتة` | نكتة مترجمة إلى العربية. |

وبناءً على طلب المستخدم، حُذفت أوامر `stt` و`sub` و`npm` search من ملفات الأوامر، وأزيلت موائمات npm المرتبطة بها والتنبيه البيئي الذي كان يذكر `sub`.

جرى اختبار واجهتي توليد صور موثقتين قبل ربطهما بـ`img`: أعادت AI Freebox خطأ 404، بينما أعادت Perchance صفحة HTML بدلاً من JSON؛ لذلك لم أضف أياً منهما كمزود قد يعطّل الأمر القائم.

## سياق المحادثة الجماعية

تُطبّق الذاكرة المشتركة على أوامر المحادثة `gptx` و`gemini` و`groq`: مفتاح السياق هو `threadID`، وتُسجّل كل رسالة مستخدم بصيغة `[اسم المستخدم]: النص`، مع استخدام اسم الحساب أو معرّف بديل آمن. لا يُمرر `senderID` كقيد لرد المتابعة، لذلك يستطيع أي عضو في المجموعة الرد على إجابة البوت ومواصلة النقاش؛ وتبقى ذاكرة كل مجموعة منفصلة عن المجموعات الأخرى. أمر المسح يمسح ذاكرة المجموعة للأمر المعني. أوامر الأدوات المنفردة مثل `img` و`tts` لا تملك سياق محادثة مستمراً، لذلك بقيت كما هي.

في المستودع G، تدعم جلسات `/gemini` و`/groq` أصلاً `thread_id` و`sender_name`؛ أضيفت إلى تعليمات النموذج ضرورة تمييز المتحدثين وعدم نسبة كلام عضو إلى آخر. أزيلت إضافة `sub` ومسار `/gemini/stt` من G.

## التحقق والحالة

اجتازت اختبارات F المحلية **13/13** (اختبارات موائمات Fahim وسياق المجموعة)، وفحوص `node --check` و`git diff --check`. اجتازت جميع حزم Go في G الأمر `go test ./...` بعد حذف الإضافة والمسار. كما تحقق البحث من عدم بقاء تسجيلات `/subtitler` أو `/gemini/stt`. لم يُشغّل البوت كاملاً أو يُختبر تفاعل Messenger الحي في هذه البيئة؛ لم تُغيّر ملفات الاعتماد أو يُنشأ lockfile.
